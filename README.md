# Scramble

A small, single-screen 2D top-down survival game built in Godot 4. Enemies spawn continuously and chase the player. The goal is to survive as long as possible.

## Play

[**Play in browser →**](https://www.sparkzz.net/games/scramble)

## Gameplay

- Enemies spawn from the screen edges and move toward you
- Shoot enemies to destroy them — your score is based on how long you survive
- You have 3 hearts. Lose them all and it's game over
- You have brief invincibility frames after taking a hit
- Enemy spawn rate increases over time — it won't stay easy

## Controls

| Input | Action |
|---|---|
| WASD / Arrow keys | Move |
| Left click | Shoot toward cursor |
| R / Space / Enter | Restart after game over |

## Built With

- [Godot 4](https://godotengine.org/) — game engine (GL Compatibility renderer)
- Exported as HTML5 for web play

## Development

This is Game 1 in a series of small games built to learn game development fundamentals. The focus was on completing a full game loop within a tight time constraint rather than polish or scalability.

Open the project in Godot 4 and run `main.tscn` to play locally.
